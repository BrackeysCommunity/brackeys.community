# Asset fixtures

Tiny files for the header readers in `packages/engine/project/inspect/` and the blob kinds in
`packages/engine/project/kinds/`.
Every file here was generated for this repository from synthetic input (solid
colours, checkers, a sine tone); none is copied from anywhere. All are dedicated
to the public domain under [CC0-1.0](https://creativecommons.org/publicdomain/zero/1.0/).

`inspect-digests.ts` runs every blob kind over these files and digests the results;
`inspect-digests-cli.ts` prints those digests, for the determinism test to compare
under Bun. They read the files at this level and in `media/`; other subfolders
such as `scene-version/` hold other tests' fixtures.

Readers only look at headers and JSON, and the font reader at the `cmap` table
(`font-cmap.ts`); the pixel, sample and glyph data are never decoded, so the
files only need to be valid enough for real tools to open.
