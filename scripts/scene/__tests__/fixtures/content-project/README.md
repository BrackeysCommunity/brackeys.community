# Content project fixture

`index.ts` adds sound and text content to a copy of the tactics project through
the scene CLI. Its media are made for this repository and dedicated to the
public domain under [CC0-1.0](https://creativecommons.org/publicdomain/zero/1.0/):

| Asset                      | Made with                                                                                |
| -------------------------- | ---------------------------------------------------------------------------------------- |
| `chime-clip`, `voice-clip` | WAVs rendered from square-wave synth patches by `synthWav`                               |
| `drone-clip`               | the engine's `packages/engine/project/__tests__/fixtures/tone.ogg` (CC0, see its README) |
| `sign-font`                | a text BMFont written by `bmfont()`: printable ASCII and "é" in 8 px cells               |
| `sign-font-page`           | the export's default icon PNG at 192 px (`defaultIconPng`)                               |
